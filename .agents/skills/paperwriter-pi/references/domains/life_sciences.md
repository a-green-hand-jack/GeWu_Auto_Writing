# Life-sciences papers

Load this during planning, drafting, and review when the assessed domain is
`life_sciences`. It relaxes no rule in `constitution.md`. This is not a
replacement for a methods specialist; it states what a paper in this domain must
contain before it is reviewable.

## Obligations

- **Methods** must state the model system/organism, sample and control design,
  reagents/instruments, and protocol to the reproducibility standard of the
  target journal. A claim without these is not reviewable.
- **Statistics**: sample sizes, biological versus technical replicates,
  uncertainty, multiple-comparison correction, blinding/randomization where
  applicable, and any exclusion criteria. P-values alone do not establish effect
  size or practical significance.
- **Consistency**: check unit and identity consistency across figures, tables,
  and text; verify that representative images or plots are not mislabeled,
  cropped to mislead, or cherry-picked. Report whether visual inspection was
  actually possible for the selected model.
- **Mandatory statements**: data and code availability, ethics/consent
  statements, and conflict-of-interest disclosure are obligations, not optional
  metadata.
- **Claim discipline**: distinguish association from causation, in-vitro from
  in-vivo, and observed effect from hypothesized mechanism. Do not let
  application vocabulary force a mechanism claim the evidence does not support.
- **Sources**: literature support must come from inspected primary studies;
  database identifiers and metadata are not content verification.

Report issues with severity and exact figure/table/section location. Missing
statistics, unreported replicates, an overstated causal or mechanism claim, or
an ethics/data-availability gap is critical.
