# Research intake workflow

For research tasks, use explicit read-only input and a separate writable output.

`INPUT_SCOPE_CONFIRMED -> SOURCES_INDEXED -> EVIDENCE_MAPPED -> STRUCTURE_CHECKED`

The installed `paperwriter-research` tool implements discovery, mapping and
validation. Read the research-intake skill before use. The source package is the
recovery point; file hashes and line ranges must still match on resume. A new
mapping creates a new revision and never overwrites its predecessor.

Report scientific review blockers after the validated research package. If domain
and venue planning was requested, follow the venue-candidates skill to produce an
evidence-linked assessment and policy candidates. For Full Draft continue through
paper-production.md, using a supplied v2 delegated draft policy or the strict
operator plan receipt. Pending scientific review does not itself prohibit a
non-final draft under delegated policy. A status of needs_review is expected for newly
extracted evidence. Only checks actually run may be reported; a source author's
validation claims remain unverified source material.
